## lfo1..6.mode -- ROOT CAUSE FOUND (cross-parameter constraint, not a write bug)
- With shape = S&H (target `lfo*.shape = RandomSH`), Serum greys out the ENVELOPE mode button; clicking it does nothing.
- Live test on the loaded instance: switched LFO1 shape S&H -> Normal only. ENVELOPE became clickable and lit when clicked.
- So `mode = Envelope` is unavailable while `shape = S&H`, and Serum drops it. The isolation tests passed because their
  shape was the default (Normal). The giant preset combines both targets. No bisect needed.
- Classification: `lfo*.mode` target is incompatible with the co-applied `lfo*.shape` target -> CONTEXT_CONFLICT, not MISMATCH.
- LFO2-6 show the same state as LFO1 (S&H, ENVELOPE greyed, 500.0 Hz, MONO on, TRIP/DOT on).

The isolated test readings ("RATIO 0.9, RELEASE 0.0") were likely the same column shift and should be re-read.
